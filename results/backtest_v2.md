## Choices and caveats

- Survivorship: Yahoo only has names listed today; delisted and acquired names are missing, so every number is an upper bound. CSE is not covered (known gap; the live trial still covers CSE).
- Prices: split-adjusted, not dividend-adjusted; dividends with an ex-date after the fill day and up to the exit day are added to gross return. XIC uses adj_close (total return).
- Main account: starts at $1,000 CAD; position size = min(cash, equity at the prior close / 3), whole shares at the limit price; a name whose one share costs more than equity / 3 is skipped for the next-ranked name (counted as skipped for price; skipped for cash when only the cash left is short). Shadow and small-cap: equity / 3, no cash limit.
- Blocking flags (v2): only bad prints and unconfirmed level shifts block a signal's 60-session lookback and are skipped inside a trade. Real large moves (jumps over 40%, bad OHLC bars) no longer block.
- A slot frees up the session after an exit (orders are placed before the open). A missed order does not hold a slot.
- Random baseline: trade-level; on each day a book placed orders it draws the same number of names from that day's candidates in the same universe (any setup; for the main book only names it could afford), same exit; a missed random order counts as no trade.
- Small-cap strict fill (sensitivity): no fill unless the day's low reached limit x 0.995.
- Factor details docs/factors.md leaves open (PM confirmed): Thrust compares volume with the 20 sessions before the signal day; Room's breakout = close above the highest high of the prior 252 sessions; ATR14 = Wilder's; a name needs 252 sessions of history before it can be scored or traded.
- Zero-volume days inside an open trade still count for exits; trades still open at the end are left out.
