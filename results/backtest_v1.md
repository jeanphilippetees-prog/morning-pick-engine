## Choices and caveats

- Survivorship (above): an upper bound. CSE not covered.
- Fill optimism: daily bars cannot show whether a limit really traded. Fills require volume on the fill day; the stricter small-cap check from the spec's bias table (fill only if the low is 0.5% below the limit) is not applied, because docs/rules.md does not include it.
- Prices: split-adjusted, not dividend-adjusted; dividends with an ex-date after the fill day and up to the exit day are added to gross return. XIC uses adj_close (total return).
- Main account starts at $30,000; position size = min(cash, equity at the prior close / 3), whole shares. Shadow and small-cap: equity at the prior close / 3, no cash limit.
- A slot frees up the session after an exit (orders are placed before the open). A missed order does not hold a slot.
- The random baseline is trade-level: on each day a book placed orders it draws the same number of names from that day's eligible, scoreable universe (any score, ignoring which names the book already held) and applies the same exit; a missed random order counts as no trade.
- Flagged bars: no signal whose 60-session lookback holds a blocking flag (jumps over 40%, bad prints, bad OHLC, level shifts); a flagged fill day is a miss; inside a trade the bar is skipped and does not count as a session.
- Factor details docs/factors.md leaves open: Thrust compares volume with the 20 sessions before the signal day; Room's breakout = close above the highest high of the prior 252 sessions; ATR14 = Wilder's. A name needs 252 sessions of history before it can be scored.
- Trades still open at the end of the data are left out.
- Regime: see the by-year tables; 2016-today has few long bear markets.
